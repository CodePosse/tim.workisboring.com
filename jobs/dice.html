Summary

Job Title: Web Developer
Location: Remote
 
 
Key Responsibilities
Design, develop, and maintain responsive web applications using React.js.
Build and maintain high-performance REST APIs using FastAPI and Python.
Integrate front-end applications with backend services and third-party APIs.
Develop reusable UI components and ensure responsive design.
Optimize application performance, scalability, and security.
Write clean, maintainable, and well-documented code.
Collaborate with product managers, designers, and QA teams throughout the development lifecycle.
Troubleshoot, debug, and resolve application issues.
Participate in code reviews and follow best development practices.
Implement authentication and authorization mechanisms (JWT, OAuth2, etc.).
Work with databases to design efficient schemas and optimize queries.
Support deployment and CI/CD processes.
 
Required Skills
7+ years of experience in full-stack web development.
Strong proficiency in React.js, JavaScript (ES6+), HTML5, and CSS3.
Experience with FastAPI and Python.
Strong understanding of RESTful API design and development.
Experience with state management libraries (Redux, Context API, Zustand, etc.).
Knowledge of asynchronous programming in Python.
Experience with relational databases such as PostgreSQL or MySQL.
Familiarity with NoSQL databases (MongoDB is a plus).
Experience with Git and version control.
Understanding of authentication and authorization (JWT, OAuth2).
Experience working with Docker and containerized applications.
Familiarity with Agile/Scrum development methodologies.
